# TNT Arrow Counter 26.3 (experimental source)
This is an uncompiled, untested Fabric 26.3 rewrite of the HUD counter based on the uploaded original JAR. It counts loaded/rendered TNT minecarts and arrow entities. Original menu and keybinds are not yet ported.

Requires JDK 25 and Gradle 9.6+; run `gradle build` with internet access to resolve Fabric dependencies. The resulting JAR (if compilation succeeds) is in `build/libs/`. This project may need API adjustments before compiling; it is **not a verified working mod**.
